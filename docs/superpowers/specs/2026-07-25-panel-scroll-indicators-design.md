# 面板短滚动条扩展设计

## 目标

将算子详情面板和底部依赖关系表的原生竖向滚动条，替换为与左侧算子目录一致的短滚动指示条。

## 视觉与交互

- 三个可滚动区域分别显示独立的竖向指示条。
- 指示条尺寸固定为 2 x 48px，使用设计系统中的中性灰色。
- 指示条随各自容器的滚动进度移动；鼠标悬停或滚动时适度提高不透明度。
- 内容不足以滚动时隐藏指示条。
- 隐藏浏览器原生竖向滚动条。
- 依赖关系表保留细横向滚动能力，避免窄窗口下表格内容被截断。

## 实现边界

- 复用现有 `ScrollIndicator.mount`，不创建第二套滚动逻辑。
- 为被挂载的滚动容器和宿主添加通用样式类，移除仅针对左侧目录的样式耦合。
- 在算子详情和依赖关系内容更新后刷新对应指示条的位置与显隐状态。
- 不改变面板尺寸、表格结构、算子数据或图谱交互。

## 验证

- 单元测试覆盖三个目标容器均已挂载滚动指示器。
- 检查指示条尺寸、显隐和滚动位置计算。
- 运行 JavaScript 语法检查与现有测试集。
- 在本地页面检查左侧目录、详情面板和依赖关系表可独立滚动，且底部横向滚动仍可用。
