# 算子详情五标签设计

## 目标

在现有算子图谱 Demo 的右侧详情面板中，增加参考“算子矩阵”Demo 的五类详情内容，并通过标签页切换：

1. 算子定义
2. 支持情况
3. 性能
4. 精度
5. API 学习

本次改动保留现有图谱、算子目录、依赖关系表和短滚动条行为。

## 交互结构

选中算子后，右侧详情由两部分组成：

- 固定摘要：算子名称、分类、计算类型、功能描述、公式数量和入出关系数量。
- 标签内容：固定摘要下方显示五个标签，点击后切换对应内容。

当前标签保存在页面状态中。选择另一个算子时保留当前标签，便于比较同类数据；切换标签时内容区域回到顶部，并刷新右侧短滚动指示条。

未选择算子时显示空状态，不显示无意义的性能或精度表格。

## 模块边界

### `operator-inspector-data.js`

负责详情数据生成，不操作 DOM。

- 将现有算子、分类和 profile 信息转换为统一详情模型。
- 为 Atlas A2、Ascend A3、Ascend A5 生成演示支持状态和性能数据。
- 为算子的支持数据类型生成精度基线。
- 提供 API 参数、调用步骤、Golden 数据和学习链接。
- 所有性能与精度数据明确标记为演示数据。

### `operator-inspector.js`

负责详情面板渲染和标签交互。

- 渲染固定摘要、标签栏和当前标签内容。
- 使用事件委托处理标签点击。
- 通过回调通知主应用标签变化和内容更新。
- 不读取图谱布局，也不修改算子选择状态。

### `app.js`

保留状态协调职责。

- 新增 `inspectorTab` 状态，默认值为 `definition`。
- 将当前算子、profile 和关系数量传给详情模块。
- 标签切换后更新状态、重绘详情并刷新滚动条。

## 统一详情模型

每个算子详情包含：

- `summary`：名称、分类、计算类型、描述和关系数量。
- `definition`：描述、公式、输入、输出和参数。
- `support`：A2/A3/A5 的状态、数据类型、限制条件、框架和确定性。
- `performance`：硬件、计算指标、数据类型、理论值、演示实测值、利用率、H100 演示对比。
- `precision`：数据类型、最大相对误差、余弦相似度和评级。
- `api`：ACLNN 名称、原型、参数说明、调用步骤、Golden 数据、源码与学习链接。

现有 profile 中缺少的数据由确定性的演示规则生成，保证同一算子每次显示一致。页面不得把生成值描述为官方兼容性或性能结论。

## 标签内容

### 算子定义

- 功能描述
- 计算公式
- 输入与输出表格
- 参数列表

### 支持情况

- Atlas A2、Ascend A3、Ascend A5 三行硬件支持信息
- 满支持、部分支持或适配中状态
- 支持数据类型与限制条件
- 支持框架和确定性

### 性能

- 理论值、演示实测值和利用率
- H100 同精度演示基线与比例
- 矩阵、注意力、访存和通信算子使用不同指标
- 显示“演示基准，非官方性能结论”说明

### 精度

- 按算子支持数据类型生成精度行
- 展示最大相对误差、余弦相似度与优/良/关注评级
- 显示“演示基准”说明

### API 学习

- ACLNN 接口名和算子原型
- 参数名称与说明
- 创建执行器、申请工作区、执行算子的学习步骤
- Golden 数据路径
- CANN 算子仓库与学习中心链接

## 视觉规范

- 使用 PTO `tab-control` 视觉语言，标签栏保持紧凑，可在窄面板中横向滚动。
- 表格采用紧凑行高、细分隔线和固定表头，不嵌套装饰卡片。
- 状态使用图标、文字和颜色共同表达，避免只依赖颜色。
- 技术标识保留英文，其余说明使用简体中文。
- 继续复用现有 `2 x 48px` 灰色短滚动指示条。

## 异常与降级

- 缺少 profile 时使用分类级默认值。
- 缺少公式、参数或输入输出时显示“暂无示例数据”，不渲染空表格。
- 不支持的硬件显示“适配中”，性能区域显示“暂无演示数据”。
- 外部学习链接使用新窗口打开，并设置安全的链接属性。

## 测试与验证

- 数据测试：26 个示例算子均可生成五类详情数据。
- 渲染测试：五个标签及关键标题存在，默认标签为“算子定义”。
- 状态测试：切换标签后选择其他算子仍保留当前标签。
- 回归测试：现有目录、图谱、滚动条、中文和部署资产测试继续通过。
- 页面验证：桌面和窄窗口下标签文字不溢出，表格可滚动，详情短滚动条正常更新。
