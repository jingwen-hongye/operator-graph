# 面板短滚动条实施计划

**目标：** 将现有短滚动指示器复用到算子详情面板和依赖关系表，并保留表格横向滚动。

## 任务 1：补充接入测试

- 新增源码级集成测试，确认左侧目录、算子详情和依赖关系表均挂载 `ScrollIndicator`。
- 保留现有滚动位置计算测试。

## 任务 2：通用化滚动指示器样式

- 由 `ScrollIndicator.mount` 为宿主和滚动容器添加通用样式类。
- 将悬停、滚动态样式从左侧目录选择器改为通用选择器。
- 隐藏原生竖向滚动条，同时为横向滚动保留 4px 轨道。

## 任务 3：接入两个目标面板

- 挂载算子详情面板的独立指示器。
- 挂载依赖关系表的独立指示器。
- 每次内容渲染完成后统一刷新三个指示器。

## 任务 4：验证

- 运行 JavaScript 语法检查。
- 运行全部 Node 测试。
- 检查本地页面资源可访问，并确认三个区域的滚动互不干扰。
